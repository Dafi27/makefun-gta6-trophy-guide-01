    How this guide works

    • Offline. Every file this app loads lives in this folder. It makes no network request at run time — open it with the network off and everything still works.
    • Saved progress. Ticks and counters are stored in your browser (localStorage). Export them to a file to back them up or move them to another machine, and import them back here.
    • Spoiler mode. With “Hide story spoilers” on, story trophies you have not earned yet show as “Hidden Trophy” — name, description and guide hidden until you earn them.
    • Missable flags. Built from the official descriptions: trophies tied to a one-time moment or choice. Do them when the guide says, before the story moves past them.
